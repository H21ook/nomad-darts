# Darts UX Fixes Implementation Plan

## Goal
Fix 9 darts-app UX issues: wizard page-skipping, Darts-row clarity, score-page appbar, exit dialog consistency, check-and-finish bugs, undo button color, match-result back navigation, per-player statistics on the match result page.

## Architecture
Client-side fixes in Next.js App Router + Redux. No window.history hash hacks — use router.replace + searchParams. Stats computation extracted into a shared pure module `src/lib/stats.ts` used by both StatsPage and MatchResult. Exit dialog restyled to the framer-motion design language of FinishConfirmation.

## Tech Stack
Next.js 16 (App Router), React 19, TypeScript, Redux Toolkit, Tailwind CSS v4, framer-motion, shadcn/ui.

## Global Constraints
- Verify with `npx tsc --noEmit`, `pnpm lint`, `pnpm build` after each task
- Dark theme only; tokens zinc + cyan in src/app/globals.css
- Icons from @tabler/icons-react; cn() from src/lib/utils.ts
- Scoring screens: touch-none select-none, onPointerDown for low latency
- UI copy Mongolian; Mongolian comments stay Mongolian
- N-player safe (no players[0]/players[1] assumptions)
- No new runtime deps; no debug logging; do not commit
